Cloud persistence (Supabase)

GitHub Pages hosts this static site; Supabase stores private records. Run the included SQL schema before connecting.

Never use a service-role key in the browser. Row-level security protects each user's records.

Backup & restore

Export JSON backups regularly. Restore replaces current local data.

Currency selection changes display only; it does not convert historic amounts. Use one reporting currency for meaningful totals.

GitHub Pages setup

  1. Create a repository and upload the project files to its root.
  2. In repository Settings → Pages, publish the main branch / root.
  3. Create a Supabase project and run supabase-schema.sql in SQL Editor.
  4. Add your published site URL to Supabase Authentication redirect URLs.
  5. Enter the Supabase URL and public key above, then sign in by email.
